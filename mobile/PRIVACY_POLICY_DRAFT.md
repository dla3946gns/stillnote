> 개발자(운영 주체) 이름, 개인정보 문의 연락처, 정책 URL, 시행일이 아직 확정되지 않았습니다. 이 항목을 확인하고 실제 최종 배포 AAB의 동작까지 재검증하기 전에는 스토어에 제출하지 마세요.

## 1. 메모 정보와 앱에서의 이용

Stillnote는 사용자가 직접 입력한 메모 제목·본문, 메모 식별자, 작성·수정 시각과 고정 여부를 기기 내 앱 전용 파일에 저장합니다. 메모에 개인정보를 입력할지 여부는 사용자에게 달려 있습니다.

검토 시점의 Android 앱 코드에는 회원가입, 로그인, 메모 서버 업로드, 자동 클라우드 동기화, 광고 SDK 및 앱 내부 분석 SDK가 구현되어 있지 않습니다. 네트워크 전송·외부 수집에 관한 최종 고지는 **배포되는 AAB와 병합된 매니페스트, SDK 구성까지 확인한 뒤** 확정해야 합니다.

## 2. 메모 공유, 복사 및 파일 내보내기

사용자가 공유 메뉴를 선택하면 Android의 시스템 공유 기능으로 사용자가 선택한 앱에 메모 텍스트를 전달합니다. 복사 기능은 Android 클립보드를 사용합니다.

사용자가 JSON 백업이나 텍스트 파일 내보내기를 선택하면 Android 시스템 문서 선택기를 통해 사용자가 고른 저장 위치로 데이터를 씁니다. JSON 백업 파일에는 메모 제목·본문 등 메모 전체 데이터가 포함될 수 있습니다. 사용자가 Google Drive 등 외부 제공자를 선택한 경우 해당 파일 제공자의 개인정보처리방침과 보관 정책이 적용될 수 있습니다.

사용자가 JSON 파일 가져오기를 선택하면 Android 시스템 파일 선택기를 통해 선택한 문서를 읽고, 기존 메모에 같은 식별자가 없는 항목을 앱 내부 파일에 추가합니다.

**사용자가 선택하지 않은 자동 백업이나 서버 업로드 기능을 제공한다고 주장하지 마세요.**

## 3. 보관 및 삭제

메모는 사용자가 삭제할 때까지 기기 전용 앱 데이터에 저장됩니다. 앱 내 삭제 시 선택한 메모가 저장 파일에서 제거되며, 화면에서 제공하는 삭제 실행 취소 기능으로 복원할 수 있습니다.

앱을 제거하거나 기기에서 앱 데이터를 삭제하면 앱 전용 저장 데이터가 제거될 수 있습니다. 단, 사용자가 별도로 생성해 보관하거나 공유한 JSON·텍스트 파일, 클립보드에 전달된 내용 및 제3자 앱/클라우드 서비스에 남은 사본은 앱을 삭제하더라도 자동으로 제거되지 않습니다. 별도로 저장한 파일은 사용자가 해당 서비스나 파일 관리자에서 직접 관리해야 합니다.

앱은 메모 내용을 별도의 개발자 서버에 보관하는 기능을 현재 제공하지 않습니다. 따라서 서버 보관 기간이나 서버 삭제 요청 기능이 있다고 기재해서는 안 됩니다.

## 4. 보안 및 처리 주의사항

메모 파일은 Android 앱 전용 내부 저장소에 저장됩니다. 앱은 운영체제의 접근 제한을 사용하지만, 별도 앱 수준의 메모 암호화 기능은 구현되어 있지 않습니다. Android 기본 보안 기능을 과장하거나 모든 상황에서 절대적으로 안전하다고 보장하는 문구를 사용하지 않습니다.

내보내거나 공유한 데이터의 보안은 사용자가 지정한 저장 위치와 앱에도 영향을 받습니다. 민감한 메모를 공유하거나 외부에 백업하기 전에 파일과 수신 대상을 확인하세요.

## 5. 문의 및 정책 변경

개인정보 처리에 관한 문의 방법은 위에 기재할 개발자 공식 연락처를 통해 제공해야 합니다. 개인정보처리방침을 변경하는 경우 변경일과 내용을 정책 페이지에 반영합니다.
