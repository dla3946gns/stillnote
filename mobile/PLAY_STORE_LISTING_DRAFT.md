## 자세한 설명

Stillnote는 떠오르는 생각을 부담 없이 기록하고 찾아볼 수 있는 메모 앱입니다.

**빠르게 적고, 원하는 메모를 다시 찾으세요.**

- 제목과 본문을 자유롭게 작성하고 저장
- 제목·본문 검색과 중요한 메모 고정
- 메모 복제, 삭제 전 확인, 삭제 실행 취소
- 텍스트 복사 및 Android 공유 기능
- 메모 텍스트 파일 저장
- JSON 파일로 전체 메모를 직접 백업하거나 가져오기
- 기기 설정에 맞추어 전환되는 라이트·다크 화면

**메모는 기기에 저장됩니다.**

현재 버전은 메모를 기기 내부 전용 파일에 저장합니다. 회원가입이나 로그인 없이 사용할 수 있으며, 자동 클라우드 동기화·기기 간 동기화 기능은 제공하지 않습니다.

휴대전화를 바꾸거나 앱을 다시 설치하기 전에 중요한 메모를 JSON 파일로 직접 내보내 보관하세요. 앱 삭제 시 기기 내부에만 있던 메모가 사라질 수 있습니다. 사용자가 선택한 공유 앱이나 파일 저장 위치를 통한 데이터 처리는 해당 서비스의 정책이 적용될 수 있습니다.
