1. 처리하는 정보와 목적

Stillnote는 사용자가 입력한 메모 제목, 본문, 메모 식별자, 작성·수정 시각 및 고정 여부를 사용자의 Android 기기 내 앱 전용 저장소에 저장합니다. 메모 정보는 작성, 편집, 검색, 고정, 삭제, 백업 및 복원 기능을 제공하기 위해 사용됩니다.

현재 Android 앱에는 회원가입, 로그인, 운영자 서버에 메모를 자동 전송하는 기능, 자동 클라우드 동기화, 광고 SDK 및 앱 사용 분석 SDK가 구현되어 있지 않습니다. 따라서 운영 주체는 앱을 사용하는 것만으로 사용자의 메모 내용을 수집하거나 서버에 보관하지 않습니다.

이메일로 문의하는 경우 사용자가 자발적으로 제공한 발신 이메일 주소, 문의 내용 및 첨부 자료가 접수될 수 있습니다. 이러한 정보는 사용자 문의에 답변하고 문제를 해결하기 위해 처리합니다. 메모 내용이나 백업 파일을 문의 메일에 첨부할 의무는 없습니다.

2. 내보내기, 공유 및 외부 서비스

'내용 복사'는 Android 클립보드에 메모 텍스트를 전달합니다. '공유'는 사용자가 선택한 다른 앱에 Android 시스템 공유 기능을 통해 내용을 전달합니다.

'전체 메모 백업' 및 '텍스트 파일 저장'은 사용자가 Android 문서 선택기에서 지정한 위치에 파일을 저장합니다. JSON 백업 파일에는 메모 본문을 포함한 모든 메모 데이터가 담길 수 있습니다. '백업 가져오기'는 사용자가 선택한 JSON 파일을 읽어 기존 메모와 중복되지 않는 메모를 기기에 저장합니다.

사용자가 Google Drive 등의 외부 파일 저장 서비스나 다른 공유 앱을 선택하면 해당 서비스로 정보가 전달되거나 저장될 수 있으며, 그 이후의 처리는 해당 서비스의 정책에 따릅니다. Stillnote가 이러한 외부 서비스에 사용자 메모를 자동 업로드하지는 않습니다.

3. 보관 기간과 삭제

기기에 저장된 메모는 사용자가 앱 안에서 삭제하거나 앱 데이터가 삭제될 때까지 기기 내에 보관됩니다. Android에서 앱을 제거하거나 앱 데이터를 초기화하면 기기 전용 저장소의 메모가 삭제될 수 있습니다. 중요한 메모는 삭제·기기 교체 전에 직접 백업하세요.

사용자가 별도로 저장한 JSON·텍스트 파일, 클립보드에 복사한 내용, 다른 앱 또는 클라우드에 보낸 사본은 Stillnote의 앱 데이터 삭제와 함께 자동으로 제거되지 않습니다. 외부 사본은 해당 저장 위치에서 별도로 삭제해야 합니다.

이메일 문의에 포함된 정보는 문의 대응 및 필요한 후속 처리에 사용하고, 더 이상 보관할 필요가 없으면 삭제합니다. 법령에 따라 보존 의무가 있는 정보는 해당 법령에 따른 기간 동안 보존할 수 있습니다.
