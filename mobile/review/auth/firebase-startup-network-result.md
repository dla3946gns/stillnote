# 로그인하지 않은 첫 실행 통신 관찰 결과

2026-10-31. **이 실행의 관찰 구간에서는 앱 UID에 귀속된 통신을 발견하지 못했다.** 측정 양성 대조는 통과했다. 데이터 수집이 전혀 없다는 전체 앱 보장은 아니다.

## 대상과 절차

- [실행 #1](https://github.com/dla3946gns/stillnote/actions/runs/41201860594), 커밋 ab0fca28e393a726350530fa74c1de8e1b04cce0, API 35 google_apis x86_64 신규 에뮬레이터, 디버그 APK.
- 실제 계정·실제 메모 없음. 로그인·가입·명시적 FirebaseAuth 인스턴스 요청 없음.
- 실행 전 약 33초, 첫 실행 후 약 97초 관찰. 이후 Wi-Fi/모바일 비활성화 명령과 재연결 구간을 거쳐 테스트 요청 전 카운터를 읽었다. 네트워크 완전 단절은 확인하지 않아 ‘완전 오프라인 검증’으로 분류하지 않는다.
- 에뮬레이터 전체 PCAP, 앱 UID별 소켓 스냅샷·netstats, 계측 코드의 자기 UID TrafficStats를 대조했다.
- 관찰 뒤 공개 엔드포인트에 테스트용 HEAD를 보내 동일 UID의 송수신 증가를 확인했다. 이 대조 요청을 앱의 일반 동작으로 간주하지 않는다.

## PCAP 해석

전체 VM 캡처에는 실행 전 55,521패킷, 첫 실행 구간 4,538패킷, 비활성화 명령 구간 112패킷, 양성 대조 구간 21패킷이 있었다. 이 수치는 Android 시스템과 다른 프로세스를 포함하며 앱 트래픽량이 아니다. 초기 VM 시스템 통신을 StillNote·reCAPTCHA 수집으로 잘못 분류하지 않는다. TLS 내용은 복호화하지 않았다.

## 결론의 한계와 후속 작업

- 자기 UID 카운터는 계측 코드가 시작된 뒤 읽었으므로 그 시작 과정도 포함한다. 양성 대조 전까지 0B였다는 관찰은 그대로 유효하지만, 모든 SDK 처리의 존재 여부를 증명하는 것은 아니다.
- 다른 UID로 위임된 동작·실기기·다른 SDK 버전·이후 장시간 동작은 관찰 범위 밖이다.
- 현재 계정 기능이 없으므로 회원가입·로그인·재설정·삭제 시 전송은 미검증이다.
- 이 결과만으로 Play 답변을 ‘수집 없음’으로 확정하거나 정책·CI 권한 허용 목록을 자동 변경하지 않는다.
- 다음으로 인증 기능 구현 시 실제 데이터 경로와 삭제 동작을 확인한다.
