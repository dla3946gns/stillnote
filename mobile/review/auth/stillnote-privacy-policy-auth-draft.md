### 1. 메모와 앱 기능

메모 제목·본문·식별자·작성 및 수정 시각·고정 여부는 Android 기기의 앱 전용 저장소에 저장하며, 작성·검색·편집·삭제·백업·복원에 사용합니다. 이 버전에는 메모를 운영자 서버로 자동 업로드하거나 기기 간 자동 동기화하는 기능이 없습니다.

현재 이 개발 버전에는 회원가입·로그인 화면과 인증 요청 기능이 없습니다. 계정 기능을 제공할 때에는 해당 데이터 처리와 삭제 방법을 방침에 반영한 후 배포합니다.

### 2. 인증 SDK와 외부 서비스

이 버전에는 Google의 Firebase Authentication SDK와 관련 reCAPTCHA 라이브러리가 포함되어 있습니다. 광고 SDK와 Google Analytics는 이번 연결에 추가하지 않았습니다.

인증 SDK는 서비스 제공과 보안·남용 방지 등을 위해 앱·SDK·플랫폼 관련 기술 정보와 IP 주소 등을 처리할 수 있습니다. 메모를 서버에 전송하지 않는다는 설명이 SDK의 기술 정보 처리까지 없다는 뜻은 아닙니다.

**게시 전 확정 필요:** 로그인하지 않은 상태의 자동 처리 여부·정보 항목·목적·수신처를 실제 초기화 동작과 대조한 뒤, 위 ‘처리할 수 있습니다’를 해당 릴리스의 구체적인 설명으로 교체합니다. reCAPTCHA 실행 여부와 데이터 범위도 별도 확정합니다.

Google 서비스의 처리는 [Firebase 개인정보 안내](https://firebase.google.com/support/privacy)와 [reCAPTCHA 공개 안내](https://docs.cloud.google.com/recaptcha/docs/disclosure-requirements-android)를 참고합니다. 공급자 자료만으로 이 앱의 모든 처리 항목을 확정하지 않습니다.

### 3. 내보내기·공유·외부 사본

‘내용 복사’는 클립보드에 메모 텍스트를 전달하고, ‘공유’는 사용자가 선택한 앱에 내용을 전달합니다. 백업·텍스트 저장은 시스템 문서 선택기에서 지정한 위치에 파일을 저장합니다. JSON 백업에는 전체 메모가 포함될 수 있습니다. 가져오기는 선택한 파일을 읽어 중복되지 않는 메모를 기기에 저장합니다.

사용자가 외부 클라우드 저장소나 공유 앱을 선택한 뒤의 처리는 해당 서비스 정책에 따릅니다. 앱의 자동 메모 업로드와는 다른 사용자 선택 동작입니다.

### 4. 보관과 삭제

기기의 메모는 앱에서 삭제하거나 앱 데이터가 삭제될 때까지 보관됩니다. 앱 제거·데이터 초기화 시 메모가 삭제될 수 있으므로 중요한 내용은 먼저 백업하세요. 별도 백업 파일·클립보드·다른 앱의 사본은 앱 데이터 삭제로 함께 제거되지 않습니다.

이메일 문의 시 발신 주소·문의 내용·첨부가 접수될 수 있습니다. 문의와 필요한 후속 처리에 사용하고 필요가 없어지면 삭제하며, 적용 법령에 보존 의무가 있으면 그 기간을 따릅니다. 문의에 메모·백업을 첨부할 의무는 없습니다.

**게시 전 확정 필요:** SDK가 처리하는 정보의 공급자별 보관·삭제 방식과 운영자의 실제 요청 처리 절차를 해당 릴리스 범위에 맞춰 추가합니다.

### 5. 보호와 사용자 선택

메모는 Android 앱 전용 저장소의 접근 제한을 적용받습니다. 앱 독자 암호화나 종단 간 암호화를 제공한다고 주장하지 않습니다. 전체 외부 전송의 암호화 여부는 최종 데이터 흐름을 검증한 후 고지합니다.

사용자는 기기 메모를 열람·수정·삭제·내보내기 할 수 있습니다. 운영자가 기기 메모를 원격으로 열람하거나 삭제하는 기능은 없습니다. 문의 정보의 열람·정정·삭제 요청은 dla3946gns@gmail.com으로 보내 주세요.

## B. 로그인 도입 시 교체·추가할 문구 — 아직 미적용

아래는 이메일/비밀번호 로그인을 구현·검증한 후 사용할 제안이다. 현재 앱 기능으로 표현하거나 A와 함께 그대로 게시하지 않는다.

**계정 정보:** “계정 기능은 선택할 수 있으며, 로그인하지 않아도 기기 내 메모 기능을 이용할 수 있습니다. 회원가입·로그인·비밀번호 재설정을 선택하면 이메일 주소와 해당 인증에 필요한 정보가 Firebase Authentication으로 전달됩니다. 비밀번호는 Firebase 인증에 사용되며 운영자 지원 이메일로 보내지 마세요. 계정 식별자와 인증 상태는 계정 기능 제공에 사용합니다.”

**처리 위치:** “Firebase Authentication의 인증 데이터는 Google의 미국 데이터센터에서 처리됩니다.” 공급자 계약상 처리자·이전 항목·시점·보관·거부 방법 등 필요한 고지는 실제 운영 및 적용 요건 확인 후 별도 완성한다. [공급자 안내](https://firebase.google.com/support/privacy)

**계정 삭제:** 앱 내 삭제 메뉴, 외부 삭제 요청 페이지, 본인 확인 방법, 처리 기간, 잔여 보관 정보와 근거를 확정한 후 실제 이용 가능한 경로를 기재한다. 존재하지 않는 메뉴·URL·삭제 완료 시간을 약속하지 않는다.

**삭제 범위:** 계정·인증 데이터, 향후 서버 권한 데이터, 기기 메모, 외부 백업을 각각 구분한다. ‘앱 삭제=온라인 계정 삭제’, ‘로그아웃=계정 삭제’, ‘계정 삭제=모든 백업 삭제’로 설명하지 않는다.
