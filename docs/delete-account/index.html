Stillnote 계정 삭제 요청

Stillnote에서 만든 Firebase 이메일 계정의 회원 탈퇴를 신청할 수 있는 경로입니다. Google·Apple 계정 자체를 삭제하는 서비스는 아닙니다.

앱을 사용할 수 있다면 더보기 → 계정 → 계정 삭제에서 직접 탈퇴할 수 있습니다.

앱을 사용할 수 없다면 아래 링크에서 웹으로 로그인하고 현재 비밀번호로 다시 본인 확인한 후 Firebase 계정을 삭제할 수 있도록 준비 중입니다.

Stillnote 계정 삭제 시작

삭제 범위

  • 삭제 대상: Stillnote Firebase Authentication 사용자 계정
  • 유지되는 데이터: 기기·브라우저의 로컬 메모와 별도로 저장한 백업 파일
  • 추가 검토 대상: Firebase 보안 로그·미래의 Plus 권한 등 별도 서버 데이터

로그인할 수 없는 경우에는 고객지원 이메일로 삭제 요청을 문의할 수 있습니다. 비밀번호·메모·백업 파일은 보내지 마세요. 본인 확인과 실제 삭제 처리는 별도 절차를 통해 진행되어야 합니다.
